## 一、sed 的概念与工作原理

### sed 是什么
sed 命令是一个**非交互式**的文本编辑器，是将一系列的编辑命令应用于一批文本的理想工具，可以对来自文本文件以及标准输入的文本进行编辑。其中，标准输入可以是来自键盘、文件重定向、字符串、变量或者是管道的文本。

sed 命令拥有**非交互式和高效**的特点，可以为用户节约大量的时间。

与 Vim 这类交互式编辑器不同：Vim 采用的是交互式文本编辑模式，可以用键盘命令来交互性地插入、删除或替换数据中的文本；而 sed 命令不同，它采用的是**流编辑模式**，最明显的特点是：在 sed 处理数据之前，需要预先提供一组规则，sed 会按照此规则来编辑数据。

### 工作原理
sed 是一种流编辑器，是文本处理中非常有用的工具，能够完美地配合正则表达式使用。处理时，把当前处理的行存储在临时缓冲区中，称为**模式空间**，接着用 sed 命令处理缓冲区中的内容，处理完成后，把缓冲区的内容送往屏幕。接着处理下一行，这样不断重复，直到文件末尾。**文件内容并没有改变。**

sed 在内存中维护两个缓冲区：

- **模式空间（pattern space）**：sed 在内存里开辟模式空间，处理文件的每个输入行，最多 8192 字节。
- **保留空间（holding space）**：sed 在内存里开辟保留空间，保存已经处理过的输入行，最多 8192 字节。

sed 的工作流程主要包括**读取、执行和显示**三个过程：

1. **读取**：sed 从输入流（文件、管道、标准输入）中读取一行内容并存储到临时的缓冲区中（又称模式空间，pattern space）。
2. **执行**：默认情况下，所有的 sed 命令都在模式空间中顺序地执行，除非指定了行的地址，否则 sed 命令将会在所有的行上依次执行。
3. **显示**：发送修改后的内容到输出流。在发送数据后，模式空间将会被清空。

重复上述过程，直到将文件中所有数据处理完毕。

> **关键结论**：默认情况下所有的 sed 命令都是在模式空间内执行的，因此输入的文件并不会发生任何变化，除非是用重定向存储输出。

### 处理流程示例
以处理 /etc/passwd、地址范围为 3-10 行为例，逐行的处理流程如下：

| 处理行 | 地址范围判定 | 执行动作 | 输出 |
| --- | --- | --- | --- |
| 第 1 行 root:x:0:0:root:/root:/bin/bash | 1 不在 3-10 范围内 | 执行默认操作：打印模式空间内容 | root:x:0:0:root:/root:/bin/bash |
| 第 2 行 bin:x:1:1:bin:/bin:/sbin/nologin | 2 不在 3-10 范围内 | 执行默认操作：打印模式空间内容 | bin:x:1:1:bin:/bin:/sbin/nologin |
| 第 3 行 daemon:x:2:2:daemon:/sbin:/sbin/nologin | 3 在 3-10 范围内 ✓ | 执行命令序列 {p;=}，再执行默认操作 | 见下方最终输出 |
| 第 4 行 adm:x:3:4:adm:/var/adm:/sbin/nologin | 4 在 3-10 范围内 ✓ | 执行命令序列 {p;=}，再执行默认操作 | 行号加内容，共两行 |

第 3 行的详细流程：

1. 读取第 3 行到模式空间；
2. 检查地址范围：3 在 3-10 范围内 ✓；
3. 执行命令序列 {p;=}：
   - 执行 p 命令：打印当前模式空间内容，输出 daemon:x:2:2:daemon:/sbin:/sbin/nologin；
   - 执行 = 命令：打印当前行号，输出 3；
4. 执行默认操作：再次打印模式空间内容（因为没有使用 -n 选项）；
5. 输出：daemon:x:2:2:daemon:/sbin:/sbin/nologin。

该行的最终输出：

```bash
daemon:x:2:2:daemon:/sbin:/sbin/nologin  ← p 命令输出
3                                      ← = 命令输出
daemon:x:2:2:daemon:/sbin:/sbin/nologin  ← 默认输出
```

第 4 行的处理流程与之类似：

1. 读取第 4 行到模式空间；
2. 检查地址范围：4 在 3-10 范围内 ✓；
3. 执行命令序列 {p;=}：
   - 执行 p 命令：打印当前模式空间内容，输出 adm:x:3:4:adm:/var/adm:/sbin/nologin；
   - 执行 = 命令：打印当前行号，输出 4；
4. 执行默认操作：再次打印模式空间内容；
5. 输出：adm:x:3:4:adm:/var/adm:/sbin/nologin。

该行的最终输出：

```bash
adm:x:3:4:adm:/var/adm:/sbin/nologin  ← p 命令输出
4                                      ← = 命令输出
adm:x:3:4:adm:/var/adm:/sbin/nologin  ← 默认输出
```

## 二、基本语法

### 语法格式
```bash
sed  -参数  '[定址符]' '操作'  文件名
```

### 常用参数
| 参数 | 说明 |
| --- | --- |
| -n、--quiet、--silent | 安静模式，不输出模式空间中的内容。一般 sed 用法中，所有来自 STDIN 的数据一般都会被列出到屏幕上；加上 -n 参数后，只有经过 sed 特殊处理的那一行才会被列出来 |
| -i | **直接编辑原文件**，而不是由屏幕输出，默认不对原文件进行操作 |
| -e | 直接在命令行模式上进行 sed 的动作编辑，多个子命令之间也可以用分号隔开，如：sed 'command1;command2...' filename，或者 sed -e 'command1' -e 'command2' ... filename |
| -r | 使用扩展正则表达式 |
| -f | 直接将 sed 的动作写在一个文件内，-f filename 则可以执行 filename 内的 sed 动作 |
| --help | 显示帮助 |
| --version | 显示版本 |
| -{} | 可组合多个命令，以分号隔开 |

使用 -e 组合多个子命令的示例：

```bash
[root@localhost ~]# sed -n  -e '7{p;=}'  -e  '9{p;=}'   /etc/passwd
shutdown:x:6:0:shutdown:/sbin:/sbin/shutdown
7
mail:x:8:12:mail:/var/spool/mail:/sbin/nologin
9
```

### 定址符
定址符用于使用数字指定处理的行区间，或者使用正则进行过滤。常用表示方法：

| 定址符 | 含义 |
| --- | --- |
| $ | 地址定位，表示文件的最后一行 |
| ^ | 正则表达式，匹配行的开头（行首位置） |

### 常用操作
| 操作 | 说明 |
| --- | --- |
| s | 替换，替换指定字符，一般搭配正则表达式 |
| d | 删除，删除选定的行 |
| p | 打印。如果同时指定行，表示打印指定行；如果不指定行，则表示打印所有内容；如果有非打印字符，则以 ASCII 码输出。其通常与 -n 选项一起使用 |
| = | 打印行号 |
| a | 增加，a 的后面可以接字串，而这些字串会在新的一行出现（目前的下一行） |
| i | 插入，i 的后面可以接字串，而这些字串会在新的一行出现（目前的上一行） |
| c | 行替换，指定行中的所有内容，替换成该选项后面的字符串 |
| y | 字符转换，转换前后的字符长度必须相同 |
| ! | 对指定行以外的所有行应用命令 |
| & | 代表匹配到的内容 |

```bash
[root@server ~]# sed  -n '/n$/p' sed1.txt   # 正则检索以n结尾的行
[root@localhost ~]# sed -n   '/n$/!p'   /etc/passwd        # 正则检索不以n结尾的行

[root@server ~]# sed  -n 'n;p' sed1.txt   # 检索偶数行

[root@server ~]# sed  -n 'p;n' sed1.txt   # 检索奇数行

[root@server ~]# sed  -n '$=' sed1.txt   # 打印文本行数
```

## 四、文本替换

### 范例文件
```bash
[root@server ~]# cp  /etc/passwd  ~/ps
[root@server ~]# cat ps
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin
daemon:x:2:2:daemon:/sbin:/sbin/nologin
adm:x:3:4:adm:/var/adm:/sbin/nologin
lp:x:4:7:lp:/var/spool/lpd:/sbin/nologin
sync:x:5:0:sync:/sbin:/bin/sync
shutdown:x:6:0:shutdown:/sbin:/sbin/shutdown
halt:x:7:0:halt:/sbin:/sbin/halt
mail:x:8:12:mail:/var/spool/mail:/sbin/nologin
……
……
```

### 替换格式
```bash
sed  '行范围s/旧字符串/新字符串/替换标记'  文件名
```

- **行范围**：使用数字表示，即对第几行到第几行进行替换处理，若省略则表示进行全文处理。
- **s**：替换动作。
- **///**：表示替换格式。

### 替换标记
| 替换标记 | 说明 |
| --- | --- |
| 数字 | 使用 1-512 之间的数字，表示指定需要替换的字符串出现第几次才进行替换 |
| g | 对数据中所有匹配到的内容进行替换，若省略 g 则只会对第一次匹配的内容进行替换 |
| p | 替换成功立刻打印，一般与 -n 一起使用 |
| w 文件名 | 将缓冲区的内容写入到指定文件中 |
| & | 使用正则表达式匹配的内容进行替换 |
| \ | 转义符，若有特殊符号或路径则需要转义 |

### 替换示例
```bash
[root@server ~]# sed  's/root/boot/g'  ps   # 替换root为boot

[root@server ~]# sed  -n 's/root/admin/p'  ps # 将每一行的第一个root替换为admin

[root@server ~]# sed -n 's/root/admin/2p'  ps  # 将本行第2次出现的root进行替换

[root@server ~]# sed -n  's/root/admin/gp'  ps # 将文本中所有root全部替换

[root@server ~]# sed -n  '4s/adm/root/gp'  ps # 将第4行内容替换

# 将ps文件第4行的/sbin/nologin替换为/bin/bash，注意：路径的/必须要转义
[root@server ~]# sed  -n  '5s/\/sbin\/nologin/\/bin\/bash/p'   ps

[root@server ~]# sed  's#/sbin/nologin#/bin/bash#g' ps  # 同上，/可写为#

[root@server ~]# sed  's#root#boot#g'  ps  # 同上，但内容为#不能更改

[root@server ~]# sed  -n '$s/:/@/gp' ps # 最后一行冒号替换为@

# 全文注释：即行首添加# ，#&表示在定位位置的左侧添加#
[root@server ~]# sed   's/^/#&/'  ps  

[root@server ~]# sed   's/^/#/'  ps  可省略& 

# 检索SSH行，在其单词左侧添加#，不能省略&，否则为替换
[root@server ~]# sed  's/SSH/#&/'  ps 

[root@server ~]# sed  's/SSH/&#/'  ps # 检索SSH行，&#表示在其单词右侧添加#

[root@server ~]# sed 's/^/@&/g;s/$/&@/g'  ps  # 所有行首及行尾添加@，可省略&

[root@server ~]# sed  '1s/^/\n/'  ps  # 第一行之前插入空白行
[root@localhost ~]# sed  '1i\\'  /test2    #1i：在第一行之前插入
[root@localhost ~]# sed  '1idddddd1123\nddddddd'  /test2 
dddddd1123
ddddddd
root:x:0:0:root:/root:/bin/bash
bin:x:1:1:bin:/bin:/sbin/nologin


[root@server ~]# sed  '$  s/$/\n/'  ps  # 最后一行之后插入空白行

# 所有小写改大写，\u表示大写，&启用正则匹配
[root@server ~]# sed 's/[a-z]/\u&/g'  ps 


[root@server ~]# sed 's/\<[a-z]/\u&/g'  ps 
[root@localhost ~]# sed -r 's/\<[a-z]*\>/\U&/g'  /test2 
[root@localhost ~]# sed -r 's/\<[a-z]*\>/\u&/g'  /test2 
```

### 替换表达式中的 \u 与 \U
在替换表达式中：

- **\u**：将紧随其后的第一个字符转为大写。在 sed 中，\u 是 GNU 扩展，用于将匹配的字符转换为大写，在非 GNU sed 上可能不可用。
- **\U**：将其后的所有字符转为大写。

### 综合应用示例
```bash
# 开启selinux
[root@server ~]# sed -i '7s/disabled/enforcing/'  /etc/selinux/config 
# 将7行的disabled替换为enforcing
[root@localhost ~]# sed  -r 's/(SELINUX=).*/\1permissive/'   /etc/selinux/config 
[root@localhost ~]# sed  -r -i.kk 's/(SELINUX=).*/\1permissive/'   /etc/selinux/config 

# 使用sed更换httpd的网页默认目录

[root@server ~]# yum  install  nginx  -y

[root@server ~]# sed -i  '42s/\/usr\/share\/nginx\/html/\/www\/zy/'  /etc/nginx/nginx.conf 
```

### 使用替换实现删除
```bash
[root@server ~]# sed  -n  's/root//gp'  ps  # 将全文中root替换为空，即删除

[root@server ~]# sed -n 's/^.//p'  ps  # 删除每行第一个字符，^.表示行首任意一个字符

[root@server ~]# sed -n 's/^#//p'  /root/anaconda-ks.cfg   # 将注释符#删除
、
[root@server ~]# sed -n 's/.$//p'  ps  # 删除每行最后一个字符

[root@server ~]# sed  '5,10s/[0-9]//g'  ps  # 删除5-10行的所有数字

# 删除所有的特殊字符（除了数字及大小写字母）,将结果写入到t1.txt文件中
[root@server ~]# sed  's/[^(a-z)(A-Z)(0-9)]//gw t1.txt'  ps 
[root@localhost ~]# sed -n 's/[^[:alnum:]]//g p'  /test2
```

## 五、删除文本

### 注意事项
d 操作用于删除文本的特定行，会删除指定的所有内容。使用该命令必须特别小心，**若忘记指定处理行的话会删除所有内容，也不会有任何输出**。

```bash
[root@server ~]# sed  -i  'd'  ps  # 全部清空
[root@server ~]# cat  ps
```

### 删除示例
```bash
[root@server ~]# cp  /root/anaconda-ks.cfg  /    # 示例文件准备

[root@server ~]# sed  '1d'  /anaconda-ks.cfg   # 删除第1行

[root@server ~]# sed  '2,5d'  /anaconda-ks.cfg  # 删除2、5行

[root@server ~]# sed  '8,$d'  /anaconda-ks.cfg  # 删除第8到结尾所有行

[root@server ~]# sed  '$d'  /anaconda-ks.cfg   # 删除最后一行

[root@server ~]# line_number=1
[root@server ~]# sed  "${line_number}d" /anaconda-ks.cfg  # 删除某行，使用变量作为行号 

[root@server ~]# sed  '/^$/d' /anaconda-ks.cfg  # 删除空白行

[root@server ~]# sed  '/System/d'  /anaconda-ks.cfg # 将包含System的整行删除

[root@server ~]# sed  -e '/System/d' -e '/Root/d'  /anaconda-ks.cfg # 多个关键字

[root@server ~]# sed '/System/d' sos.conf | sed '/Root/d' /anaconda-ks.cfg # 同上

[root@server ~]# sed '/3/,/5/d' /anaconda-ks.cfg # 删除3所在行到5所在行之间的内容（包含）

[root@server ~]# sed  '/^#/d'  /anaconda-ks.cfg 
# 注意：默认情况下，删除的内容只是在输出的结果中消失了，没有增减-i参数时源文件不变
```

## 六、插入文本

### 注意事项
使用 a（append）动作在指定行的下一行追加一行，使用 i（insert）动作在指定行前插入一行，两者格式相同。

```bash
sed  '行范围a(或i)\新文本'   文件名
```

### 插入示例
```bash
[root@server ~]# cat  /etc/hosts
[root@server ~]# cp  /etc/hosts  ~/

# 尾部添加一行
[root@server ~]# sed  -i  '$a\192.168.48.132  www.openlab.com'  ~/hosts 

# 某行之前添加
[root@server ~]# sed  -i  '3i\192.168.48.131  www.openlab.com'  ~/hosts 

# 文本匹配后插入
[root@server ~]# sed  -i  '/131/i\192.168.48.130  www.openlab.com'  ~/hosts 

------------------------
[root@localhost ~]# sed  -f /root/s.sed  /mianshi 
This is the first line  # 在第1行前插入文本
___abc___
___deHif___
___abc___
___def___
[root@localhost ~]# cat s.sed 
s/hello/Hi/      # 替换 hello 为 Hi
/^$/d            # 删除空行
s/[0-9]/_/g      # 将所有数字替换为下划线
1i\This is the first line  # 在第1行前插入文本
```

### 空文件限制
sed 是基于数据流处理的命令，若无内容则无法处理，所以**空文件不能插入**。

```bash
[root@server ~]# touch t2.txt
[root@server ~]# cat t2.txt 
[root@server ~]# sed -i '$a\xiao ming,18,98.5'  t2.txt
[root@server ~]# cat t2.txt 
```

### 面试题 2
文件内容如下：

```bash
    123abc456
    456def123
    567abc789
    789def567
```

要求输出：

```bash
456ABC123
123DEF456
789ABC567
567DEF789
```

解法一（借助 tr）：

```bash
[root@server ~]# sed -r 's/([0-9]{3})(.*)([0-9]{3})/\3\2\1/' b.txt | tr -s '[a-z]' '[A-Z]'
456ABC123
123DEF456
789ABC567
567DEF789
```

解法二（在 sed 中直接转换大小写）：

```bash
[root@localhost ~]# sed -r 's/([0-9]{3})([a-z]{3})([0-9]{3})/\3\U\2\1/'  /shouji2
456ABC123
123DEF456
789ABC567
567DEF789

[root@localhost ~]# sed -En 's/([0-9]{3})(.*)([0-9]{3})/\3\u\2\1/ p'  /mianshi 
456Abc123
123Def456
789Abc567
567Def789
[root@localhost ~]# sed -En 's/([0-9]{3})(.*)([0-9]{3})/\3\U\2\1/ p'  /mianshi 
456ABC123
123DEF456
789ABC567
567DEF789
```

> **再次强调**：在替换表达式中，\u 将紧随其后的第一个字符转为大写；\U 将其后的所有字符转为大写。
