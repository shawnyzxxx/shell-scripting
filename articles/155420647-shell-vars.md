# RHCSE Shell 02：变量详解

## 文章导读
本篇是 RHCSE Shell 课程的变量专题，系统讲解 Shell 变量的**增删改查**、**生效范围（局部/全局/环境变量）**、**配置文件加载顺序**、**位置参数与内置变量**以及**变量运算**。由于 Shell 变量本质上都是字符串，掌握变量操作是编写 Shell 脚本的基础，适合 Linux 运维与脚本学习者。

## 一、变量的基本操作：增删改查

### 1. 创建变量（增）
**语法**：`变量名=值`

**定义变量的几种方式：**
1. **直接赋值**：`name="li si"`
2. **read 命令**：`read name`
3. **使用位置参数**（`$1 $2 $3…`）：`name=$1`
4. **命令输入**：`name=$(whoami)`

```bash
# 创建字符串变量
name="张三"
message="Hello World"

# 创建数字变量（Shell 中所有变量本质上都是字符串）
age=25
count=100

# 创建带空格的变量（必须用引号）
full_name="Li Si"
file_path="/home/user/documents"

# 使用命令结果创建变量
current_time=$(date)
file_count=$(ls | wc -l)
```

**注意事项：**
- 值中有特殊字符或空格时，必须用引号
- 变量名只能包含字母、数字、下划线，且不能以数字开头

### 2. 读取变量（查）
**语法**：`$变量名` 或 `${变量名}`

```bash
echo $PATH
echo ${PATH}
printf "$PATH\n"

# 基本读取
echo $name
echo "我的名字是: $name"

# 使用花括号明确边界（推荐）
echo "我的名字是: ${name}"

# 防止歧义的例子
file="document"
echo "这是${file}1.txt"    # 正确：这是document1.txt
echo "这是$file1.txt"       # 错误：尝试读取不存在的变量file1
```
> 使用 `${变量名}` 能明确变量边界，避免与后续字符拼接产生歧义，是推荐写法。

**查看所有变量：**

| 命令 | 作用 |
|---|---|
| `set` | 查看所有的变量和函数 |
| `declare` | 查看所有的变量和函数 |
| `env` | 显示所有的全局变量 |

```bash
[root@rhce ~]# set | grep alice
_=alice
a=alice
[root@rhce ~]# declare | grep alice
_=alice
a=alice
[root@rhce ~]# env | grep alice
[root@rhce ~]#
```

### 3. 修改变量（改）
直接重新赋值，或在原有值基础上修改：

```bash
name="张三"
echo "原名: $name"
name="李四"
echo "改名后: $name"

# 在原有值基础上修改
count=10
count=$((count + 5))    # 算术运算
echo "新的数量: $count"

path="/home/user"
path="${path}/documents"
echo "新路径: $path"
```

### 4. 删除变量（删）
使用 `unset` 命令：

```bash
# 创建变量
temp_var="临时数据"
echo "删除前: $temp_var"

# 删除变量
unset temp_var
```

## 二、变量的生效范围

### 1. 局部变量（Local Variables）
**定义**：只在函数内部生效的变量，使用 `local` 声明。

```bash
var="全局变量"
demo_local() {
    local local_var="我是局部变量"
    echo "函数内部: local_var = $local_var"

    # 没有 local 关键字也会创建变量（但这是危险的做法）
    temp_var="临时变量"   # 这实际上会创建全局变量
    echo "$var"
}

demo_local
echo "========"
echo $local_var
echo "$var"
```

**测试：**
```bash
[root@rhce ~]# bash /shell/jubu.sh
函数内部: local_var = 我是局部变量
全局变量
========
（local_var 在函数外不可见）
全局变量
```

局部变量仅在定义它的范围内生效。通过 `~/.bash_profile` 定义的变量：

```bash
[root@localhost ~]# vim .bash_profile     # ~/.bash_profile 是用户独享的配置文件
# 在文件最后新增一行：
a=1000

[root@localhost ~]# echo $a
kunpeng          # 未更新变量文件时，a 值未变化

[root@localhost ~]# source .bash_profile   # 更新变量文件后
[root@localhost ~]# echo $a
1000

[root@localhost ~]# bash          # 打开一个新的 bash
[root@localhost ~]# echo $a
                  # a 变量未定义
[root@localhost ~]# exit
[root@localhost ~]# su - root     # 以登录方式切换用户，会自动读取 .bash_profile
[root@localhost ~]# echo $a
1000            # a 变量值生效
```

**用户配置文件**

| 范围 | 文件 |
|---|---|
| 当前用户生效 | `~/.bashrc`、`~/.bash_profile` |
| 所有用户生效 | `/etc/bashrc`、`/etc/profile`、`/etc/profile.d/` |

**文件加载顺序**（以 `su - student` 登录为例）：
```
[root@node13 ~]# su - student
Last login: Sun Sep 18 23:06:43 CST 2022 on pts/0
/etc/profile
/etc/profile.d/name3.sh
/etc/bashrc
/home/student/.bash_profile
/home/student/.bashrc
/etc/bashrc
```

非登录方式（`su student`）只加载：
```
/home/student/.bashrc
/etc/bashrc
/etc/profile.d/name3.sh
```

### 2. 全局变量（Global Variables）
**定义**：在整个脚本中可见，但不传递给子进程。

```bash
#!/bin/bash

# 全局变量定义
global_var="我是全局变量"

demo_global() {
    echo "函数内部访问全局变量: $global_var"
    # 修改全局变量
    global_var="函数内修改了全局变量"
}

echo "函数调用前: $global_var"
demo_global
echo "函数调用后: $global_var"
```

### 3. 环境变量（Environment Variables）
**定义**：对当前 Shell 及其所有子进程都有效，使用 `export` 导出，可被子进程继承。

通过 `/etc/profile` 设置全局生效的环境变量：

```bash
[root@localhost ~]# vim /etc/profile     # /etc/profile 是系统配置文件，所有用户共享
# 在文件最后新增一行：
b=2000

[root@localhost ~]# echo $b
2020            # 变量未更新

[root@localhost ~]# source /etc/profile
[root@localhost ~]# echo $b
2000            # 变量值发生变化

[root@localhost ~]# bash           # 打开新的 bash
[root@localhost ~]# echo $b        # 变量未定义
[root@localhost ~]# exit
[root@localhost ~]# su - root      # 登录方式切换，自动读取 /etc/profile
[root@localhost ~]# echo $b
2000            # b 变量值生效

[root@localhost ~]# useradd huawei
[root@localhost ~]# su - huawei   # 切换到该用户
[huawei@localhost ~]$ echo $b
2000            # 变量 b 对所有用户生效
```

### 4. 位置参数与内置变量
**位置参数**：脚本传入的参数，通过 `$1`、`$2` 等引用；`$@`、`$*` 表示所有参数。

```bash
#!/bin/bash
echo "=====\$@======"
for i in "$@"
do
    echo $i
done
echo "==========="
for i in "zhang san xixi" "wang wu"
do
    echo $i
done
echo "=====\$*======"
for i in "$*"
do
    echo $i
done
```

**测试：**
```bash
[root@rhce shell2]# bash /shell2/test6.sh hang san xixi wang wu
=====$@======
hang
san
xixi
wang
wu
===========
zhang san xixi
wang wu
=====$*======
hang san xixi wang wu
```

**内置变量示例脚本 `/shell/name.sh`：**

```bash
#!/bin/bash
#########################
#File name:/shell/name.sh
#Version:v1.0
#Email:admin@test.com
#Created time:2025-11-20 19:19:57
#Description:
#########################
echo "当前脚本的名称是：$0"
echo "传入参数个数: $#"
echo "传入的第一个参数： $1"
echo "传入的第三个参数： $3"
echo "=======\$*=========="
echo "传入的所有参数：$*"
echo "=======\$@=========="
echo "传入的所有参数：$@"
echo "当前shell的PID ： $$"
```

**测试：**
```bash
[root@rhce shell]# bash /shell/name.sh hehe xixi haha lele "zhang san"
当前脚本的名称是：/shell/name.sh
传入参数个数: 5
传入的第一个参数： hehe
传入的第三个参数： haha
=======$*==========
传入的所有参数：hehe xixi haha lele zhang san
=======$@==========
传入的所有参数：hehe xixi haha lele zhang san
当前shell的PID ： 1682
```

**常用内置变量：**

| 变量 | 含义 |
|---|---|
| `$0` | 当前脚本的名称 |
| `$#` | 传入参数的个数 |
| `$1` `$2` … | 第 1、2 个位置参数 |
| `$*` | 所有参数，作为一个整体 |
| `$@` | 所有参数，逐个展开 |
| `$$` | 当前 Shell 的 PID |

## 三、变量的运算
Shell 中的变量运算主要包括算术运算、字符串运算、逻辑运算等。由于 Shell 变量默认都是字符串类型，进行数学运算需要特殊处理。

### 1. 基本算术运算符
```bash
#!/bin/bash
a=10
b=3

# 加法
sum=$((a + b))
echo "$a + $b = $sum"    # 输出: 10 + 3 = 13

# 减法
diff=$((a - b))
echo "$a - $b = $diff"   # 输出: 10 - 3 = 7

# 乘法
product=$((a * b))
echo "$a * $b = $product"  # 输出: 10 * 3 = 30

# 除法（整数除法）
quotient=$((a / b))
echo "$a / $b = $quotient"  # 输出: 10 / 3 = 3

# 取模（求余数）
remainder=$((a % b))
echo "$a % $b = $remainder"  # 输出: 10 % 3 = 1
```

### 2. 算术运算的几种语法

**方法一：`$(( ))` 算术扩展（推荐）**
最常用的方法：

```bash
result=$((10 + 5 * 2))
echo $result      # 输出: 20

# 支持变量
x=15
y=4
echo $((x / y))  # 输出: 3
```

**方法二：`let` 命令**
使用 `let` 命令，不需要 `$`：

```bash
let "z = 5 + 3"
echo $z       # 输出: 8

# 复合运算
let "z += 2"    # z = z + 2
let "z *= 3"    # z = z * 3
let "z++"       # 自增
let "z--"       # 自减
echo $z       # 输出: 30
```

**方法三：`expr` 命令**
注意：运算符前后要有空格，乘法需要转义：

```bash
result=$(expr 10 + 5)
echo $result      # 输出: 15

# 乘法需要转义
result=$(expr 10 \* 2)
```

## 四、小结
Shell 变量是脚本编程的基石。本篇梳理了变量的**增删改查**基本操作，区分了**局部、全局、环境变量**三种生效范围及配置文件加载顺序，讲解了**位置参数与内置变量**，并总结了**算术运算的三种写法**。编写脚本时，建议优先使用 `${变量名}` 明确边界、用 `$(( ))` 做算术运算，从而写出健壮、易读的 Shell 脚本。
