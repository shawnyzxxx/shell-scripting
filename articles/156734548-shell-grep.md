# RHCSE Shell 06：grep 文本过滤详解

## 文章导读
`grep` 是 Linux 中一种强大的文件搜索过滤工具，可以按照正则表达式检索文件内容，并把匹配的结果显示到屏幕上（匹配的内容会标红）。本文系统讲解 grep 的常用参数、过滤示例、正则表达式（基本正则 BRE 与扩展正则 ERE）、POSIX 字符类，并附大量课堂练习，适合 Shell 文本处理学习者。

## 一、grep 的作用与参数

**作用**：grep 是 Linux 中强大的文件搜索过滤工具，可按正则表达式检索文件内容，匹配内容会标红显示。

**常用参数**

| 参数 | 说明 |
|---|---|
| `-i` | 忽略大小写 |
| `-c` | 统计匹配的行数 |
| `-v` | 取反，不显示匹配的行 |
| `-w` | 匹配单词 |
| `-E` | 等价于 egrep，即启用扩展正则表达式 |
| `-n` | 显示行号 |
| `-A数字` | 匹配行及以下 n 行 |
| `-B数字` | 匹配行及以上 n 行 |
| `-C数字` | 匹配行及上下 n 行 |
| `-o` | 只显示匹配的内容 |

**注意事项**
- **工作方式**：grep 可以在一个或多个文件中检索，如果条件中包含了空格，需要使用双引号引起
- **工作结果**：如果搜索成功则返回 0 状态码，否则为 1 状态码

**操作对象文件：`/etc/passwd`**
- **作用**：记录账户的信息，共分为 7 段，使用冒号分割
- **意义**：账户名：密码代号 x：UID：GID：注释：家目录：登录的 Shell
- **注意**：最后一段 `/sbin/nologin` 表示不允许登录

**grep 过滤命令示例**
```bash
[root@shawn ~]# grep -n "root" /etc/passwd
[root@shawn ~]# grep -n "sshd" /etc/passwd
[root@shawn ~]# grep -n "/sbin/nologin" /etc/passwd
[root@shawn ~]# grep -c "/bin/bash" /etc/passwd
[root@shawn ~]# grep "/bin/bash" /etc/passwd | wc -l
[root@shawn ~]# grep -nv "/sbin/nologin" /etc/passwd
[root@shawn ~]# grep -ni "d" /etc/passwd
[root@shawn ~]# grep -nA2 "ftp" /etc/passwd
[root@shawn ~]# grep -nB3 "ftp" /etc/passwd
[root@shawn ~]# grep -nC3 "ftp" /etc/passwd
```

## 二、grep 练习

**file.txt 文件内容（各列含义）**
- 第 1 列：城市位置编号
- 第 2 列：月份
- 第 3 列：存储代码及出库年份
- 第 4 列：产品代号
- 第 5 列：产品统一标价
- 第 6 列：标识号
- 第 7 列：合格数量

```
48      Dec      3BC1977 LPSX   68.00   LVX2A   138
483     Sept     5AP1996 USP    65.00   LVX2C   189
47      Oct      3ZL1998 LPSX   43.00   KVM9D   512

```

**题目与参考命令**

| 题目 | 命令 |
|---|---|
| 1、含有 "48" 字符串的行的总数 | `grep "48" /root/file.txt` |
| 2、显示含有 "48" 字符串的所有行的行号 | `grep -n "48" /root/file.txt` |
| 3、精确匹配只含有 "48" 字符串的行 | `grep -o "48" /root/file.txt` |
| 4、抽取代码为 484 和 483 的城市位置 | `awk '$1=="484" || $1=="483" {print $1}' /root/file.txt`（$n 表示第 n 列） |
| 5、显示行首不是 4 或 8 | `grep -v '^[48]' /root/file.txt` |
| 6、显示含有九月份的行 | `grep -i 'sept' /root/file.txt`（`-i` 忽略大小写） |
| 7、显示以 K 开头，以 D 结尾的所有代码 | `awk '$4 ~ /^K.*D$/' /root/file.txt` |
| 8、显示头两个是大写字母，中间两个任意，并以 C 结尾的代码 | `awk '$4 ~ /^[A-Z]{2}..C$/ {print $4}' /root/file.txt` |
| 9、查询所有以 5 开始以 1996 或 1998 结尾的记录 | `awk '$3 ~ /^5.*199[68]$/' /root/file.txt` |

## 三、正则表达式

在进行程序设计的过程中，用户会不可避免地遇到处理某些文本的情况，有时还需要查找符合某些复杂规则的字符串。如果单纯依靠编程语言本身，往往需要复杂的代码实现；而使用正则表达式，则可以用非常简短的代码完成。

正则表达式是通过一些特殊字符的排列，用以查找、替换、删除一行或多行文字字符串。由于语法简练、功能强大，得到了许多编程语言的支持，包括 Python、Java、C++、Perl 以及 Shell 等。

### 1. 基本正则表达式（BRE）
基本正则表达式（Basic Regular Expression，BRE），又称为标准正则表达式，是最早制订的正则表达式规范，仅支持最基本的元字符集。它是 POSIX 规范制订的两种正则表达式语法标准之一，另一种是扩展正则表达式。

**常见元字符**

| 元字符 | 说明 |
|---|---|
| `^` | 以某个字符开头 |
| `$` | 以某个字符结尾 |
| `.` | 匹配任意单字符 |
| `*` | 对前一项进行 0 次或多次重复匹配 |
| `{m,n}` | 将前一项字符重复 m-n 次，如 `{m,}`、`{,n}`、`{m,n}` |
| `[]` | 对方括号内的单字符进行匹配 |
| `[^]` | 不匹配方括号内的单字符 |
| `^[]` | 匹配以某个字符开头的行 |
| `()` | 定义一个子表达式 |
| 词首 `\<` 或 `\b`、词尾锚定 `\>` 或 `\b` | 其后面的任意字符必须作为单词首部出现；其前面的任意字符必须作为单词尾部出现 |
| `\` | 转义字符，让一些特殊符号失效 |

**POSIX 字符类**
POSIX 字符类是一个形如 `[:...:]` 的特殊元序列（meta sequence），可用于匹配特定的字符范围。

| 字符类 | 描述 | 示例 |
|---|---|---|
| `[:alnum:]` | 匹配任意一个字母或数字字符 | `[[:alnum:]]+` |
| `[:alpha:]` | 匹配任意一个字母字符（含大小写） | `[[:alpha:]]` |
| `[:blank:]` | 空格与制表符 | `[[:blank:]]*` |
| `[:digit:]` | 匹配任意一个数字字符 | `[[:digit:]]?` |
| `[:lower:]` | 匹配小写字母 | `[[:lower:]]` |
| `[:upper:]` | 匹配大写字母 | `([[:upper:]]+)?` |
| `[:punct:]` | 匹配标点符号 | `[[:punct:]]` |
| `[:space:]` | 匹配包括换行符、回车在内的所有空白符 | `[[:space:]]+` |
| `[:graph:]` | 匹配任何可见且可打印的字符 | `[[:graph:]]` |
| `[:xdigit:]` | 任何一个十六进制数（0-9、a-f、A-F） | `[[:xdigit:]]+` |
| `[:cntrl:]` | 任何一个控制字符（ASCII 前 32 个字符） | `[[:cntrl:]]` |
| `[:print:]` | 任何一个可以打印的字符 | `[[:print:]]` |

**`[ab]`：检索包含 a 或包含 b 的行信息，`[ ]` 中只能表示一个内容**
```bash
# 检索包含 d 或者 D 的行信息
[root@server ~]# grep -n [dD] /etc/passwd
[root@server ~]# grep -ni d /etc/passwd
[root@server ~]# grep -E "(d|D)" /etc/passwd
# 检索包含字母 o 的行信息
[root@server ~]# grep -n [o] /etc/passwd
```

**`[^ ]`：根据关键字检索后反向显示（反向着色）**
```bash
# 检索不包含字母 o 的行信息
[root@server ~]# grep -n [^o] /etc/passwd
# 检索不以 r 开头且包含 oot 的行信息
[root@server ~]# grep -n [^r]oot /etc/passwd
```

**`[-]`：表示范围，如 `[0-9]`、`[a-z]`、`[A-Z]`、`[a-zA-Z]`**
```bash
# 检索包含 7-9 的行信息
[root@server ~]# grep -n [7-9] /etc/passwd
# 检索包含大写字母的行信息
[root@server ~]# grep -n [A-Z] /etc/passwd
# 检索包含数字和字母的行信息
[root@server ~]# grep -n [0-9a-zA-Z] /root/anaconda-ks.cfg
# 上例改写
[root@server ~]# grep -n [[:alnum:]] /root/anaconda-ks.cfg
```

**`^` 行首与 `$` 行尾**
```bash
# 检索 root 开头的行信息
[root@server ~]# grep -n ^root /etc/passwd
# 检索以 # 开头的行信息
[root@server ~]# grep -n "^#" /root/anaconda-ks.cfg
# 检索以数字结尾的行信息
[root@server ~]# grep -n "[0-9]$" /root/anaconda-ks.cfg
# 检索空白行
[root@server ~]# grep -n "^$" /root/anaconda-ks.cfg
```
> 注意：`^[root]` 表示检索以 r 开头或 o 开头或 t 开头（独立对待）；`^root` 表示检索 root 开头（整体对待）；`[^root]` 表示检索不包含 r 或 o 或 t 的（反向着色）。**`^[]` 与 `[^]` 有本质区别**。

**点 `.` 与星号 `*`**
```bash
# 检索以 r 开头 t 结尾中间只有 2 个字符的行信息
[root@server ~]# grep -n r..t /etc/passwd
# 检索至少包含 1 个 w 字母的行信息
[root@server ~]# grep -n ww* /etc/passwd
# 检索至少包含 2 个字母 o 的行信息
[root@server ~]# grep -n ooo* /etc/passwd
# 检索包含 (.) 的行信息，需要加双引号
[root@server ~]# grep -n "\." /etc/passwd
```

**定义指定重复次数 `{m,n}`**
```bash

operator:x:11:0:operator:/root:/sbin/nologin
[root@localhost ~]# grep "ro\{1\}" /etc/passwd

chrony:x:980:979:chrony system user:/var/lib/chrony:/sbin/nologin
```

**定义子表达式 `()`**
```bash
[root@localhost ~]# grep "\(not\)\{1\}.*\1" /test
She always encourages me notnot  not to give up and tries to cheer me up by coming up not with good solutions.
[root@localhost ~]# grep "\(not\)\{1\}..\1" /test

[root@localhost ~]# grep "\(not\)\{2\}..\1" /test
She always encourages me notnot  not to give up and tries to cheer me up by coming up not with good solutions.
```

**练习：匹配开头字母和结尾字母相同的行 / 开头单词和结尾单词相同的行**

**用 grep 演示 POSIX 字符类**
```bash
# [[:blank:]] （空格/Tab）
[root@localhost ~]# echo -e "hello\tworld\nhi world\nno-space" | grep "[[:blank:]]"
hello\tworld
hi world

# [[:space:]] （所有空白符）
[root@localhost ~]# echo -e "line1\nline2 with space\n\tindented" | grep "[[:space:]]"
line2 with space
\tindented

# [[:xdigit:]] （十六进制数字，A-F a-f 0-9 均被匹配）

Hex: A1b9 DEADBEEF xyz

# \x01 是 ASCII 控制符 Start of Header
echo -e "normal\x01text" | grep "[[:cntrl:]]" --color=auto
```

### 2. 扩展正则表达式（ERE）
扩展正则表达式（Extended Regular Expression，ERE）支持比基本正则表达式更多的元字符。前面介绍的 `\^`、`$`、`.`、`*`、`[]`、`[^]` 这 6 个元字符在扩展正则表达式中都得到支持，且意义和用法完全相同。接下来重点介绍扩展正则表达式中新增的元字符。

| 元字符 | 说明 |
|---|---|
| `?` | 将前一项字符进行 0 次或 1 次的重复匹配 |
| `+` | 将前一项进行 1 次或多次的重复匹配 |
| `(|)` | 匹配 `|` 符号左边或者右边的字符 |

```bash
# 显示 /etc/passwd 中以 bash 结尾的行信息
[root@server ~]# grep -n "bash$" /etc/passwd

# 找出 /etc/passwd 中包含三位数或者四位数的行信息
[root@server ~]# grep -n "\<[0-9]\{3,4\}\>" /etc/passwd

# 上例改写
[root@server ~]# grep -n "\<[[:digit:]]\{3,4\}\>" /etc/passwd

# 显示 /etc/passwd 文件中 root、sshd、chrony 的相关信息（需使用 egrep 支持扩展正则）
[root@server ~]# egrep -n "(root|sshd|chrony)" /etc/passwd
# (|) 会对 | 左右两边的整体内容进行匹配

# echo 输出一个绝对路径，使用 egrep 取出其基名
[root@server ~]# echo /etc/yum.repos.d/ | egrep -o [^/]+/?$
```
> 表达式 `[^/]+/?$` 分解：`[^/]` 匹配任何不是斜杠 `/` 的字符；`+` 匹配前面的元素一次或多次；`/?` 匹配可选的一个斜杠（0 次或 1 次）；`$` 匹配行尾。

**检索 ifconfig 命令结果的 1-255 之间的整数**
```bash
[root@server ~]# ifconfig | egrep -o "\<([1-9]|[1-9][0-9]|1[0-9][0-9]|2[0-4][0-9]|25[0-5])\>"
[root@localhost ~]# ifconfig | grep -E '([0-9]{1,3}\.){3}[0-9]{1,3}'
        inet 192.168.5.128  netmask 255.255.255.0  broadcast 192.168.5.255
        inet 127.0.0.1  netmask 255.0.0.0
[root@localhost ~]# ifconfig | grep -Eo '([0-9]{1,3}\.){3}[0-9]{1,3}'
192.168.5.128
255.255.255.0
192.168.5.255
127.0.0.1
255.0.0.0
[root@localhost ~]# ifconfig | grep -Eo 'inet ([0-9]{1,3}\.){3}[0-9]{1,3}[[:space:]]+netmask ([0-9]{1,3}\.){3}[0-9]{1,3}'
inet 192.168.5.128  netmask 255.255.255.0
inet 127.0.0.1  netmask 255.0.0.0
```

grep 是 Linux 文本过滤的核心工具。掌握常用参数（`-n`、`-c`、`-v`、`-i`、`-A/B/C`、`-o`、`-E`），理解基本正则（BRE）与扩展正则（ERE）的元字符差异、POSIX 字符类、词首词尾锚定，就能灵活应对各类文本检索需求。实际使用中注意引号与转义，配合管道与 awk 可以完成更复杂的文本处理。
