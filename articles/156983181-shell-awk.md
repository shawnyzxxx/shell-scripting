## 一、awk 概述

### 概念

awk 是 Linux 以及 UNIX 环境中现有的功能最强大的数据处理工具。awk 的名称得自其三位创始人 Alfred Aho、Peter Weinberger 和 Brian Kernighan 姓氏的首个字母。

awk 是一种处理文本数据的编程语言，适合文本处理和报表生成。awk 的设计使它非常适合处理由行和列组成的文本数据。

awk 还是一种编程语言环境，它提供了正则表达式的匹配、流程控制、运算符、表达式、变量以及函数等一系列程序设计语言所具备的特性，并从 C 语言中获取了一些优秀的思想。

### 工作流程

awk 处理数据的过程可以归纳为四步：

1. **第一步**：自动从指定的数据文件中读取行文本。
2. **第二步**：自动更新 awk 的内置系统变量的值，例如列数变量 `NF`、行数变量 `NR`、行变量 `$0`，以及各个列变量 `$1`、`$2` 等等。
3. **第三步**：依次执行程序中所有的匹配模式及其操作。
4. **第四步**：当执行完程序中所有的匹配模式及其操作之后，如果数据文件中仍有未读取的数据行，则返回第 1 步，重复执行第 1～4 步的操作。

## 二、awk 命令语法

### 组成

任何 awk 语句都由模式（pattern）和动作（action）两部分组成。

- **模式**：由一组用于测试输入行是否需要执行动作的规则组成。
- **动作**：包含语句、函数和表达式的执行过程。同一花括号 `{}` 内的多个表达式（赋值、打印等），必须用分号 `;` 分隔。

简言之，模式决定动作何时触发以及触发事件，动作执行对输入行的处理。

### 格式

```bash
awk 'BEGIN{ commands } pattern{ commands } END{ commands }' [INPUTFILE…]
# 以上三部分均可选
```

## 三、BEGIN 模式与 END 模式

### BEGIN 模式

BEGIN 模式是一种特殊的内置模式，其执行时机为 awk 程序刚开始执行、尚未读取任何数据之前。因此该模式对应的操作只被执行一次；当 awk 读取数据之后，BEGIN 模式便不再成立。

用户可以把与数据文件无关、且在程序整个生命周期中只需执行一次的代码放在 BEGIN 模式对应的操作中，一般用于打印报告的标题和更改内置变量的值。

### END 模式

END 模式是 awk 的另一种特殊模式，执行时机与 BEGIN 模式恰好相反：它在 awk 处理完所有数据、即将退出程序时成立，在此之前 END 模式并不成立。无论数据文件中包含多少行数据，该模式对应的操作在整个程序生命周期中只执行一次。因此一般把善后工作放在 END 模式对应的操作中，用于打印总结性的描述或数值总和。

### 示例

```bash
[root@rhce ~]# awk 'BEGIN{sum=10} { sum += $1 }; END { print sum }' file

[root@server ~]# awk 'BEGIN {print "BEGIN..."} {print $0} END {print "The End"}' /etc/fstab

[root@server ~]# awk 'BEGIN {print "line one \n line two \n line three"}'

[root@server ~]# awk 'BEGIN {print "this is  test"}'
```

## 四、awk 的输出

### 格式

```bash
awk 'BEGIN{ commands } {print item1，item2，……} END{ commands }' [INPUTFILE…]
```

- 各项目之间使用逗号隔开，而输出时则以空格字符分隔。
- 输出的 item 可以是字符串或数值、当前记录的字段（如 `$1`）、变量或 awk 的表达式。

## 五、awk 程序的执行方式

### 通过命令行执行

```bash
[root@server ~]# vim input
# 输入多个回车符（空行）

[root@server ~]# awk '/^$/{print "This is  a  blank  line"}' input
```

### 调用脚本文件执行

当 awk 程序语句较多时，可以把所有语句写在一个脚本文件中，再通过 awk 命令解释并执行其中的语句。调用脚本的语法如下：

```bash
awk -f program-file file
```

- `-f` 选项表示从脚本文件中读取 awk 程序语句。
- `program-file` 表示 awk 脚本文件名称。
- `file` 表示要处理的数据文件。

```bash
[root@server ~]# vim scr.awk   # 新建 awk 脚本，输入以下内容
/^$/{print "This is  a  blank  line"}

[root@server ~]# awk -f scr.awk input
```

### 直接使用脚本文件执行

除了输入 awk 命令之外，还可以通过类似 Shell 脚本的方式执行 awk 程序。这种方式需要在 awk 程序中指定命令解释器，并赋予脚本文件可执行权限。指定命令解释器的语法如下：

```bash
#!/bin/awk -f
```

以上语句必须位于脚本文件的第一行。通过以下命令执行 awk 程序：

```bash
./awk-script.awk file
```

```bash
[root@server ~]# vim scr.awk
#!/bin/awk -f    # 注意需要增加，表示使用什么解释器来执行
/^$/{print "This is a blank  line."}

[root@server ~]# chmod o+x scr.awk
[root@server ~]# ./scr.awk input
```

## 六、记录（行）和域（字段）

### 概念

awk 认为输入文件是结构化的：awk 将每个输入**文件行**定义为记录，行中的每个字符串定义为域（字段）。域之间用空格、Tab 键或其他符号分隔，分隔域的符号叫做分隔符，默认为空格或 Tab。

awk 使用域操作符 `$` 来指定执行动作的域。域操作符 `$` 后面跟数字或变量来标识域的位置，每条记录的域从 1 开始编号，如 `$1` 表示第一个域，`$0` 表示所有域。

```bash
# 准备示例文件
[root@server ~]# vim awk1.txt
# 输入以下内容
Li xiaoming xian 13311111111
zhang cuihua baoji 13322222222
wang xiaoer xianyang 13333333333
```

```bash
[root@server ~]# awk '{print $0}' awk1.txt    # 所有域
Li xiaoming xian 13311111111
zhang cuihua baoji 13322222222
wang xiaoer xianyang 13333333333

[root@server ~]# awk '{print $1}' awk1.txt   # 第一个域，即第一列
Li
zhang
wang

[root@server ~]# awk '{print $2}' awk1.txt
xiaoming
cuihua
xiaoer

[root@server ~]# awk '{print $3}' awk1.txt
xian
baoji
xianyang

[root@server ~]# awk '{print $4}' awk1.txt   # 第4列
13311111111
13322222222
13333333333
```

### 域操作符后可跟变量或表达式

```bash
[root@server ~]# awk 'BEGIN {one=1;two=2} {print $(one+two)}' awk1.txt
xian
baoji
xianyang
```

```bash
[root@server ~]# awk '/^[^#]/{print $3}' /etc/fstab
xfs
xfs
swap
# ^[^#] 表示不以 # 开头的行
```

```bash
# 检索包含 swap 的第一列信息
[root@server ~]# awk '/swap/{print $1}' /etc/fstab
```

## 七、字段分隔符：-F、FS 与 OFS

### 使用 -F 参数指定域的间隔符

```bash
# 查询文件中的所有账户名
[root@server ~]# awk -F ":" '{print $1}' /etc/passwd # 指定冒号为分隔符

# 查询文件中的 UID 与 GID
[root@server ~]# awk -F ":" '{print $3,$4}' /etc/passwd

[root@localhost ~]# awk -v FS=: 'NR<=3{print $1}' /etc/passwd
root
bin
daemon
```

```bash
[root@rhce ~]# cat file
1 2
1
1 2
1 9
[root@rhce ~]# awk -F 2 '{ print $1 }' file
1
1
1
1 9
[root@rhce ~]# awk -F 2 '{ print $2 }' file




```

关于 `-F 2` 的说明：

- `-F 2`：指定字符 `2` 为字段分隔符（不是数字 2、不是空格，仅匹配字符 "2"）。
- `{print $1}`：输出每行按 `2` 拆分后的第一个字段。
- 拆分规则：
  - 若行中包含 `2`：以 `2` 为界，左边所有字符是 `$1`，右边是 `$2`（无内容则为空）。
  - 若行中无 `2`：整行内容作为 `$1`（因为没有分隔符，只有 1 个字段）。

### 通过系统变量 FS 改变分隔符

设置 FS 变量即可改变域分隔符。

```bash
[root@server ~]# awk 'BEGIN {FS=":"} {print $2}' /etc/passwd
[root@rhce ~]# awk 'FS=":"{ print $1}' /etc/passwd
root:x:0:0:root:/root:/bin/bash
bin
daemon
adm
lp
sync
shutdown
halt
mail
operator
games
ftp
nobody
systemd-coredump
dbus
tss
sssd
sshd
chrony
systemd-oom
redhat
```

处理第 1 行的完整流程：

1. **读取行**：把行 1 内容读入 `$0` → `$0 = root:x:0:0:root:/root:/bin/bash`。
2. **拆分字段**：此时 FS 还是默认值（空格），而行 1 中没有空格，所以整行被视为 1 个字段 → `$1 = root:x:0:0:root:/root:/bin/bash`（`$2`、`$3` 等为空）。
3. **执行 pattern**：`FS=":"` → 把 FS 的值从「空格」改成 `:`（赋值完成），该表达式返回值是 `":"`（非空 = 真）。
4. **执行 action**：`print $1` → 输出 `$1` 的内容（整行）。

处理第 2 行的完整流程：

1. **读取行**：把行 2 内容读入 `$0` → `$0 = bin:x:1:1:bin:/bin:/sbin/nologin`。
2. **拆分字段**：此时 FS 已经被第 1 行的 pattern 改成 `:`，按 `:` 拆分行 2 → `$1=bin`、`$2=x`、`$3=1`……。
3. **执行 pattern**：`FS=":"` → 再次赋值（FS 已经是 `:`，无变化），返回值 `":"`（真）。
4. **执行 action**：`print $1` → 输出 `bin`。

处理第 3 行及以后：

和第 2 行逻辑完全一致——FS 已经是 `:`，按 `:` 拆分后 `$1` 是用户名（daemon、adm、lp 等），所以只输出 `$1`。

### OFS（输出字段分隔符）

注意：同一花括号 `{}` 内的多个表达式（赋值、打印等），必须用分号 `;` 分隔。

注意：逗号是 awk 的「输出字段分隔符触发符」，会自动用 OFS 分隔 `$2` 和 `$3`。

```bash
[root@rhce ~]# awk 'BEGIN{FS=":";OFS="-"} { print $2  $3}' /etc/passwd
x0
x1
x2
x3
....
[root@rhce ~]# awk 'BEGIN{FS=":";OFS="-"} { print $2,  $3}' /etc/passwd
x-0
x-1
x-2
x-3
x-4
....
```

先补充分号修复语法错误，命令如下：

```bash
awk '{FS=":"; OFS="-"} {print $2$3}' /etc/passwd
```

执行结果分析（仍有问题）：

- 第一行输出为空：因为 FS 在第一行处理时才赋值，拆分字段时 FS 还是默认空格，行 1 无空格，所以 `$2`/`$3` 为空，拼接后还是空。
- 第二行及以后：输出按 `:` 拆分的 `$2` 和 `$3` 拼接结果（比如第二行 `bin:x:1:1:...` 的 `$2=x`、`$3=1`，输出 `x1`）。
- 且 `OFS="-"` 完全没生效，因为写的是 `$2$3`，是直接拼接，不是用 OFS 分隔。

完全正确的写法需要同时解决「语法错误 + FS 生效时机 + OFS 正确使用」，满足两个核心：

1. FS/OFS 放在 BEGIN 块中（读取第一行前就生效）；
2. 用 `$2 OFS $3`（即 `$2, $3`，而非 `$2$3`）触发 OFS 的分隔作用。

```bash
# 写法1：BEGIN块设置FS/OFS，用OFS分隔$2和$3
awk 'BEGIN{FS=":"; OFS="-"} {print $2, $3}' /etc/passwd

# 写法2：等价简化（-F指定FS，BEGIN设置OFS）
awk -F: 'BEGIN{OFS="-"} {print $2, $3}' /etc/passwd
```

关键解释：

- `BEGIN{FS=":"; OFS="-"}`：BEGIN 块在读取任何行之前执行，确保 FS/OFS 从第一行开始就生效；`FS=":"` 表示按冒号拆分字段；`OFS="-"` 表示输出字段分隔符（仅在 print 中用逗号分隔字段时生效）。
- `print $2, $3`：逗号是 awk 的「输出字段分隔符触发符」，会自动用 OFS（`-`）分隔 `$2` 和 `$3`；若写 `print $2$3`，是直接拼接 `$2` 和 `$3`（比如 `x` 和 `1` 拼成 `x1`），OFS 不会生效。

## 八、NR、NF、FILENAME 等内置变量

### 概念

- **NR**：表示记录数，即行号。
- **NF**：表示记录的域数量，即本行的总列数。
- **FILENAME**：处理的文件名。

### 示例

```bash
[root@server ~]# awk '{print NF,NR,$0} END {print FILENAME}' awk1.txt
4 1 Li xiaoming xian 13311111111
4 2 zhang cuihua baoji 13322222222
4 3 wang xiaoer xianyang 13333333333
awk1.txt

[root@localhost ~]# awk '{print $NF"@"NR"@"$0}' awk1.txt
13311111111@1@Li xiaoming xian 13311111111
13322222222@2@zhang cuihua baoji 13322222222
13333333333@3@wang xiaoer xianyang 13333333333

[root@localhost ~]# awk -v OFS=@ '{print $NF","NR","$0}' awk1.txt

[root@localhost ~]# awk -F : '{print $NF }' /etc/passwd   # 打印每行最后一个字段
等价于
[root@localhost ~]# awk -F : '{print $7 }' /etc/passwd

[root@localhost ~]# awk -F : '{print NF }' /etc/passwd   # 打印每行的字段数
```

```bash
[root@server ~]# awk '{print "第",NR,"行","有",NF,"域" > "/root/t1.txt"}' awk1.txt
[root@localhost ~]# awk '{print "第",NR,"行","有",NF,"域" }' awk1.txt > /root/t1.txt

[root@server ~]# cat t1.txt
第 1 行 有 4 域
第 2 行 有 4 域
第 3 行 有 4 域
```

## 九、awk 的变量

### 变量概念与命名

与其他程序设计语言一样，awk 本身支持变量的定义、引用以及参与相关运算，并包含许多内置的系统变量。变量的作用是存储数据，由变量名和值两部分组成：变量名是引用变量值的途径，变量值是内存空间中存储的用户数据。

awk 的变量名只能包括字母、数字和下划线，且不能以数字开头。例如 `abc`、`a`、`z`、`a123` 都是合法的变量名，而 `123abc` 是非法的变量名。另外，awk 的变量名区分大小写，因此 `X` 和 `x` 分别表示不同的变量。

awk 中的变量类型分为字符串和数值两种，但定义变量时无需指定类型，awk 会根据变量所处的环境自动判断。**如果没有指定值，数值类型变量的缺省值为 0，字符串类型变量的缺省值为空串。**

### 内置变量一览

| 变量 | 作用 |
| --- | --- |
| `$0` | 记录变量，表示所有列的内容 |
| `$n` | 字段变量，表示第 n 个列的内容 |
| `NF` | 当前行的列个数 |
| `NR` | 显示每一行的行号 |
| `FS` | 输入字段分隔符，默认值是空格或制表符，可用 `-F` 指定分隔符 |
| `OFS` | 输出字段分隔符，`OFS="#"` 指定输出分隔符为 `#` |
| `RS` | 记录分隔符，默认值是换行符 `\n` |
| `ORS` | 输出结果的行间隔符 |
| `ENVIRON` | 当前 shell 环境变量及其值的关联数组 |
| `FIELDWIDTHS` | 由空格分隔的一列数字，定义了每个数据字段的确切宽度 |
| `FNR` | 当前数据文件中的数据行数 |

助记说明：

- `FS` 输入字段分隔符（field separator）
- `RS` 输入记录分隔符（record separator）
- `OFS` 输出字段分隔符（output field separator）
- `ORS` 输出记录分隔符（output record separator）
- `NF` 数据文件中的字段总数（number fields）
- `NR` 已处理的输入记录数（行数）（number record）
- `FNR` 当前数据文件中的数据行数（file number record）

### 示例

```bash
# 准备数据文件
[root@server ~]# vim awk2.txt  # 输入以下内容
zhangsan 68 88 92 45 71
lisi     77 99 63 52 84
wangwu   61 80 93 77 81
```

```bash
[root@server ~]# awk -f test.awk awk2.txt
```

```bash
/root/.local/bin:/root/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin
[root@localhost ~]# awk 'BEGIN{print  ENVIRON["SHELL"] }'
/bin/bash
[root@localhost ~]# awk 'BEGIN{print  ENVIRON["PWD"] }'
```


### 用户自定义变量

awk 允许用户自定义自己的变量，以便在程序代码中使用。变量名命名规则与大多数编程语言相同，只能使用字母、数字和下划线，且不能以数字开头；awk 变量名称区分字符大小写。

```bash
[root@server ~]# awk 'BEGIN {test="hello world";print test}'
hello world
[root@server ~]# awk -v test="china" 'BEGIN {print test}'
china
```

## 十、awk 常用选项

| 选项 | 作用 | 核心场景 |
| --- | --- | --- |
| `-F` | 指定字段分隔符 | 拆分字段（如处理 `/etc/passwd`） |
| `-v` | 定义变量（传递外部值） | 动态传参（如 shell 变量到 awk） |
| `-f` | 加载 awk 脚本文件 | 复杂逻辑（替代长命令） |

### -F：指定字段分隔符（最常用）

作用：设置 FS（字段分隔符），等价于 `BEGIN{FS="分隔符"}`，用于按指定字符或正则拆分每行的字段。

语法：

```bash
awk -F'分隔符' '动作' 文件
```

```bash
# 按冒号(:)拆分/etc/passwd，打印第1个字段（用户名）
awk -F: '{print $1}' /etc/passwd

# 按“空格或冒号”（正则）拆分，打印第2个字段
awk -F'[ :]' '{print $2}' /etc/passwd
```

### -v：定义 awk 变量（传递外部值）

作用：在 awk 执行前定义变量（可传递 shell 变量到 awk 内部），避免硬编码。

语法：

```bash
awk -v 变量名=值 '动作' 文件
```

```bash
# 定义变量num=10，计算每行第1个字段+10的结果
awk -v num=10 '{print $1 + num}' 数字文件.txt

# 传递shell变量到awk（比如shell变量user=root）
user=root
awk -v u="$user" '$1 == u {print $0}' /etc/passwd
```

### -f：加载 awk 脚本文件（复杂逻辑）

作用：当 awk 命令太复杂时，将逻辑写在脚本文件中，用 `-f` 加载执行，替代命令行写长代码。

语法：


## 十一、格式化输出 printf

### 格式

格式化输出与 C 语言格式相同。

```bash
printf("format\n",输出列表项)
```

`format` 是一种控制输出格式的字符串，以 `%` 开头，后跟上一个字符，如：

| 格式说明符 | 含义 |
| --- | --- |
| `%c` | 字符 |
| `%d`，`%i` | 十进制整数 |
| `%u` | 无符号整数 |
| `%f` | 浮点数 |
| `%e`，`%E` | 科学计数法 |
| `%s` | 字符串 |
| `%%` | 显示一个 `%` |

### 修饰符

`format` 说明符有修饰符：

- `N`：显示宽度；
- `-`：左对齐；
- `+`：显示数值的正负号。

### 注意事项

- `printf` 语句不会打印 `\n`，需要手动写出换行符。
- 字符串一般使用双引号作为定界符。

### 示例

```bash
[root@server ~]# awk 'BEGIN{printf("%E\n",123.4567)}'

```

```bash

```

```bash
[root@server ~]# ifconfig  ens32 | awk  'NR==2 {print  $2}'
```

### 条件运算符（三目运算符）

格式：

```bash
expression?value1:value2
```

```bash
[root@server ~]# vim awk3.txt

3 6
10 9
3 3

[root@server ~]# awk '{max=$1>$2?$1:$2 ; print  NR ,"max=",max}' awk3.txt
# max=$1>$2?$1:$2 三元运算符（条件判断简写），核心逻辑是“找$1和$2的最大值”
```

原文给出的逐行执行结果如下：

| 处理行数 | `$1` | `$2` | 三元运算符判断 | max 值 | print 输出结果 |
| --- | --- | --- | --- | --- | --- |
| 第 1 行 | 10 | 5 | 10>5 → 真 | 10 | 1 max= 10 |
| 第 2 行 | 8 | 25 | 8>25 → 假 | 25 | 2 max= 25 |
| 第 3 行 | 100 | 99 | 100>99 → 真 | 100 | 3 max= 100 |

### 逻辑运算符

符号：`&&`、`||`、`!`

### 关系运算符

符号：`>`、`<`、`>=`、`<=`、`==`、`!=`、`~`（匹配）、`!~`（不匹配）

```bash
# 查询/etc/passwd文件第三列小于10以下的数据，且仅列出账号与第三列
[root@server ~]# awk -F : '$3<10 {print $1 "\t" $3}' /etc/passwd

[root@server ~]# awk 'BEGIN{a=1;b=2;print (a>2&&b>1,a=1||b>1)}'

```

> awk 是编程语言，用「1 = 真、0 = 假」适配数值 / 逻辑计算；Shell 是命令解释器，用「0 = 真（命令成功）、非 0 = 假（命令失败）」适配命令执行状态。
>
> 记忆技巧：
> - awk：逻辑真假 → 真 1 假 0（和编程一致）
> - Shell：命令成败 → 成 0 败非 0（和 UNIX 传统一致）

## 十五、awk 数组

### 关联数组

为了在单个变量中存储多个值，许多编程语言都提供数组。awk 使用**关联数组**提供数组功能。

关联数组与数字数组不同之处在于它的索引值可以是任意文本字符串。不需要用连续的数字来标识数组中的数据元素，而是用各种字符串来引用值。每个索引字符串都必须能够唯一地标识出赋给它的数据元素。

### 定义数组变量

可以用标准赋值语句来定义数组变量，格式如下：

```bash
var[index] = element
```

其中 `var` 是变量名，`index` 是关联数组的索引值，`element` 是数据元素值。awk 中数组变量的示例：

```bash
capital["Illinois"] = "Springfield"
capital["Indiana"] = "Indianapolis"
capital["Ohio"] = "Columbus"
```

在引用数组变量时，必须包含索引值来提取相应的数据元素值：

```bash
[root@kittod ~]# awk 'BEGIN{
> capital["Illinois"] = "Springfield"
> print capital["Illinois"]
> }'
Springfield
```

在引用数组变量时会得到数据元素的值，数据元素值是数字值时也一样：

```bash
[root@kittod ~]# awk 'BEGIN{
> var[1] = 34
> var[2] = 3
> total = var[1] + var[2]
> print total
> }'
37
```

如上例所示，可以像使用 awk 程序中的其他变量一样使用数组变量。

### 遍历数组变量

关联数组变量的问题在于可能无法预知索引值是什么。与使用连续数字作为索引的数字数组不同，关联数组的索引可以是任何东西。要在 awk 中遍历一个关联数组，可以使用 for 语句的一种特殊形式：

```awk
for (var in array)
{
statements
}
```

这个 for 语句会在每次循环时将关联数组 `array` 的下一个索引值赋给变量 `var`，然后执行一遍 `statements`。重要的是记住：该变量中存储的是**索引值**而不是数组元素值。可以把这个变量用作数组的索引，轻松取出数据元素值。

```bash
[root@kittod ~]# awk 'BEGIN{
> var["a"] = 1
> var["g"] = 2
> var["m"] = 3
> var["u"] = 4
> for (test in var)
> {
> print "Index:",test," - Value:",var[test]
> }
> }'
Index: u  - Value: 4
Index: m  - Value: 3
Index: a  - Value: 1
Index: g  - Value: 2
```

```bash
awk 'BEGIN{
# 1. 定义关联数组var，赋值4个键值对
var["a"] = 1  # 键为字符串"a"，值为1
var["g"] = 2  # 键为"g"，值为2
var["m"] = 3  # 键为"m"，值为3
var["u"] = 4  # 键为"u"，值为4

# 2. for-in循环遍历关联数组
for (test in var)  # test是循环变量，依次取var的每个键
{
# 3. 打印键和对应的值
print "Index:",test," - Value:",var[test]
}
}'
[root@rhce ~]# awk 'BEGIN{var["a"]=1;var["b"]=2;var["c"]=3; for(test in var){print "Index:",test," - Value:",var[test]}} '
Index: a  - Value: 1
Index: b  - Value: 2
Index: c  - Value: 3
```

要点：

- **核心功能**：演示 awk 关联数组（键值对）的定义和 for-in 遍历。
- **BEGIN 块**：仅在 awk 初始化阶段执行，无输入文件时也能运行。
- **关联数组特性**：键可以是字符串，存储无序，for-in 遍历顺序 ≠ 插入顺序。
- **for-in 循环**：循环变量取的是「键」而非「值」，需用数组名[键]取值。
- 索引值不会按任何特定顺序返回，但都能指向对应的数据元素值。不能指望返回的值有固定顺序，只能保证索引值和数据值是对应的。

### 利用数组统计字符串出现次数

awk 中可以利用数值进行运算，例如：

```bash
[root@server ~]# awk 'BEGIN{a=1;print ++a}'
2
```

变量值为字符串时的自增运算：

```bash
[root@server ~]# awk 'BEGIN{a="test" ; print a,++a}'
test 1
```

> 注意：awk 中字符串参与运算时会被当做数值 0；当访问一个不存在的元素时，该数组元素被赋值为空字符串，若该空字符串参与运算会被当做数值 0。

**例1：统计文本中 IP 出现次数**

```bash
# 准备文本
[root@server ~]# vim iptest.txt
192.168.48.1
192.168.48.2
192.168.48.5
192.168.48.1
192.168.48.3
192.168.48.1
192.168.48.5
192.168.48.2
192.168.48.4
192.168.48.1
```

```bash
[root@server ~]# awk '{count[$1]++} END{ for(i in count) {print i,"次数:",count[i]}}' iptest.txt
192.168.48.1 次数: 4
192.168.48.2 次数: 2
192.168.48.3 次数: 1
192.168.48.4 次数: 1
192.168.48.5 次数: 2
```

**分析**

阶段 1：初始化阶段（awk 启动时）

- awk 加载指令，默认设置 FS（字段分隔符）为「任意空白字符」（空格 / 制表符），因此每行的第一个字段（`$1`）就是 IP 地址；
- 初始化关联数组 `count`（空数组，无任何键值对）；
- 无 BEGIN 块，直接进入「逐行处理阶段」。

阶段 2：逐行处理阶段（核心统计逻辑）

awk 会逐行读取 iptest.txt，对每一行执行 `{count[$1]++}`，这是统计次数的核心。拆解 `count[$1]++` 的逻辑：

- `$1`：当前行的第一个字段（IP 地址，如第一行的 192.168.48.1）；
- `count[$1]`：以 IP 为键的关联数组元素，awk 对「未定义的数组元素」默认值为 0；
- `++`：自增运算符，等价于 `count[$1] = count[$1] + 1`。

逐行执行过程（关键行示例）：

| 处理行数 | 当前行 `$1`（IP） | count[$1] 的变化（执行 ++ 前→执行后） | 数组状态（简化） |
| --- | --- | --- | --- |
| 第 1 行 | 192.168.48.1 | 0（未定义）→ 1 | count["192.168.48.1"]=1 |
| 第 2 行 | 192.168.48.1 | 1 → 2 | count["192.168.48.1"]=2 |
| 第 3 行 | 192.168.48.1 | 2 → 3 | count["192.168.48.1"]=3 |
| 第 4 行 | 192.168.48.1 | 3 → 4 | count["192.168.48.1"]=4 |
| 第 5 行 | 192.168.48.2 | 0 → 1 | count["192.168.48.2"]=1 |
| 第 6 行 | 192.168.48.2 | 1 → 2 | count["192.168.48.2"]=2 |
| 第 7 行 | 192.168.48.3 | 0 → 1 | count["192.168.48.3"]=1 |
| 第 8 行 | 192.168.48.4 | 0 → 1 | count["192.168.48.4"]=1 |
| 第 9 行 | 192.168.48.5 | 0 → 1 | count["192.168.48.5"]=1 |
| 第 10 行 | 192.168.48.5 | 1 → 2 | count["192.168.48.5"]=2 |

关键细节：

- 无 pattern（仅 `{count[$1]++}`），因此所有行都会执行这个动作；
- `count[$1]++` 是「先取值，后自增」，但此处无需关注顺序，仅需累加次数，效果等价于 `count[$1] += 1`。

阶段 3：END 块汇总阶段（所有行处理完毕后）

当 iptest.txt 的最后一行处理完成，awk 进入 END 块（仅执行一次），执行 `for(i in count) {print i,"次数:",count[i]}`：

- `for(i in count)`：遍历关联数组 count 的所有键（即所有出现过的 IP 地址），循环变量 i 依次取每个 IP；
- `print i,"次数:",count[i]`：`i` 是当前遍历到的 IP（数组的键），`count[i]` 是该 IP 对应的出现次数（数组的值）；逗号 `,` 分隔的内容用 OFS（默认空格）分隔，因此输出格式为「IP 次数：次数值」。

遍历过程（数组键的顺序由 awk 哈希规则决定，非插入顺序）：

1. 第一次循环：`i=192.168.48.1` → 打印 `192.168.48.1 次数: 4`；
2. 第二次循环：`i=192.168.48.2` → 打印 `192.168.48.2 次数: 2`；
3. 第三次循环：`i=192.168.48.3` → 打印 `192.168.48.3 次数: 1`；
4. 第四次循环：`i=192.168.48.4` → 打印 `192.168.48.4 次数: 1`；
5. 第五次循环：`i=192.168.48.5` → 打印 `192.168.48.5 次数: 2`。

关键点：

- `count[$1]++`：awk 关联数组的经典累加用法，利用「未定义数组元素默认值为 0」的特性，实现「首次出现记 1，重复出现累加」；
- END 块：仅在所有行处理完毕后执行，用于汇总 / 输出统计结果（若没有 END 块，awk 不会输出任何内容，因为逐行处理阶段只有累加、无打印动作）；
- `for(i in count)`：遍历关联数组的所有键，是 awk 汇总数组的标准方式（遍历顺序无序，由哈希值决定）。

**例2：查看服务器连接状态并汇总**

```bash
[root@server ~]# netstat -an  |  awk  '/^tcp/{++s[$NF]} END{for(i in s) {print  i,s[i]}}'
LISTEN 8
ESTABLISHED 2
```

分析：

- `netstat -an`：查看连接；
- `/^tcp/`：通过正则过滤；
- `$NF`：过滤结果中每行的最后一个字段。

**练习：统计 /etc/passwd 文件中各种 shell 的个数**

```bash
[root@localhost ~]# awk -F : '{shell[$NF]++}  END{for (i in shell) print i "有:" shell[i] "个" }' /etc/passwd
```

### 删除数组变量

从关联数组中删除数组索引要用一个特殊命令：

```bash
delete array[index]
```

删除命令会从数组中删除关联索引值和相关的数据元素值。

```bash
[root@kittod ~]# awk 'BEGIN{
> var["a"] = 1
> var["g"] = 2
> for (test in var)
> {
> print "Index:",test," - Value:",var[test]
> }
> delete var["g"]
> print "---"
> for (test in var)
> print "Index:",test," - Value:",var[test]
> }'
Index: a  - Value: 1
Index: g  - Value: 2
---
Index: a  - Value: 1
```

一旦从关联数组中删除了索引值，就没法再用它来提取元素值。

```bash
[root@localhost ~]# awk -F : ' BEGIN{printf "%20s %20s\n","SHELL","个数" ;print "==========================================="} {shell[$NF]++;delete shell["/sbin/nologin"]}  END{for (i in shell) printf "%20s %20s\n" ,i , shell[i] }' /etc/passwd
               SHELL                   个数
===========================================
           /bin/sync                    1
           /bin/bash                    2
          /sbin/halt                    1
   /usr/sbin/nologin                    5
      /sbin/shutdown                    1
[root@localhost ~]# awk -F : '{shell[$NF]++}  END{delete shell["/sbin/nologin"];for (i in shell) printf "%20s %20s\n" ,i , shell[i] }' /etc/passwd
           /bin/sync                    1
           /bin/bash                    2
          /sbin/halt                    1
   /usr/sbin/nologin                    5
      /sbin/shutdown                    1
```
